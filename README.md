# 🚀 JobEzz — منصة العمل والخدمات الشاملة (JobEzz Ultimate Platform)

> **JobEzz** هي المنصة الرقمية الشاملة الأولى في ليبيا والمُصممة لربط الباحثين عن عمل بالشركات، وتوفير خدمات منزلية ومشاريع عند الطلب (On-Demand Services)، بالإضافة إلى أكاديمية تدريبية معتمدة للتعلم والتطوير المهني.

---

## 🌟 مميزات المنصة

- **💼 سوق الوظائف (Jobs Marketplace)**: تصفح والتقديم على وظائف بدوام كامل، جزئي، أو عن بُعد مع نظام تتبع الطلبات.
- **🔧 الخدمات عند الطلب (On-Demand Services)**: طلب فنيين ومزودي خدمات محليين (سباكة، كهرباء، تنظيف، صيانة، إلخ) مع التتبع المباشر للخريطة وتقدير التكلفة.
- **🎓 أكاديمية JobEzz (Academy & Courses)**: دورات تدريبية تفاعلية، اختبارات تقييمية، وشهادات إتمام معتمدة.
- **🛡️ لوحة أدمن أسطورية (Legendary Admin Dashboard)**: لوحة تحكم كاملة لإدارة المستخدمين، المحتوى، التحليلات، واختبارات A/B والنزاعات.
- **⚡ تطبيق جوال متكامل (Expo / React Native App)**: تطبيق أندرويد و iOS يدعم الوضع الداكن والتنقل السلس واللغتين العربية والإنجليزية.

## 🚀 دليل التشغيل والتجربة الاختبارية

### 1. تشغيل موقع الويب ولوحة التحكم (Web Prototype & Admin)

أسهل طريقة للتشغيل في نظام ويندوز:
- انقر مزدوجاً على الملف: **`start-web.bat`**

أو عبر السطر البرمجي:
```bash
npm run web
```
سيفتح المتصفح تلقائياً على الرابط: `http://localhost:3000/index-legendary.html`
- لوحة التحكم الإدارية: `http://localhost:3000/admin-legendary.html`
- معرض نظام التصميم: `http://localhost:3000/showcase.html`

---

### 2. تشغيل تطبيق المحمول (Expo Mobile App)

أسهل طريقة للتشغيل في نظام ويندوز:
- انقر مزدوجاً على الملف: **`start-mobile.bat`**

أو عبر السطر البرمجي:
```bash
npm run app
```
- للتجربة على المتصفح عبر **Expo Web**:
```bash
npm run app:web
```

---

### 3. تدقيق واختبار الأنواع (TypeScript Typecheck)

لتشغيل فحص كود تطبيق المحمول والتأكد من خلوه من أي أخطاء:
```bash
npm run typecheck
```
