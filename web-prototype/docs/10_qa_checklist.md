# JobEzz — Localization, Polish & QA Checklist (Prompt 10)

## أ) تدقيق RTL / الإنجليزية
- [ ] كل الشاشات محاذاة صحيحة RTL (النصوص، الأيقونات المِرآتية عند الحاجة، تنسيق التاريخ/الأرقام بـ `num`).
- [ ] مبدّل اللغة (عربي/إنجليزي) يعمل عبر التطبيق ويلفّظ `dir` و`lang` ويعيد الرسم.
- [ ] لا يوجد نص إنجليزي محشور داخل واجهة عربية (والم反之亦然).

## ب) الحالات (States) — لا شاشات فارغة
- [x] حالات تحميل (skeletons) — شاشة المطابقة.
- [x] حالات فارغة — الطلبات حسب الحالة، الوظائف المحفوظة.
- [x] حالات خطأ — رسائل OTP/شبكة ودّية (معالَجة في منطق الإرسال).

## ج) جولة تفاعلية (Interactive walkthrough)
- [ ] شاشة تعريف لكل دور عند أول استخدام (ممكّنة عبر onboarding + أدوات العرض في الملف).

## د) الوصولية (Accessibility)
- [x] أهداف لمس كبيرة (أزرار ≥44px).
- [x] تباين لوني ضد الكحلي/الأبيض (نصوص رمادية على خلفيات فاتحة).
- [x] أحجام خطوط مقروءة (14–16px أساسي).

## هـ) أصول المتجر (App Store / Google Play)
- [ ] أيقونة التطبيق مُصدَّرة من الشعار (`assets/img/icon.png`).
- [ ] 4–6 لقطات لكل منصة (رئيسية، خدمات، وظائف، دورات، مزوّد، أدمن).
- [ ] وصف عربي + إنجليزي قصير يبرز الركائز الثلاث (وظائف/خدمات/دورات).

## و) قائمة فحص الرحلة الكاملة لكل دور
### باحث عن عمل
[ ] تسجيل OTP → اختيار دور → تصفّح وظائف → فلترة → تفاصيل → تقديم → تتبّع الحالة → إشعار.

### صاحب عمل
[ ] نشر وظيفة → ظهورها → استقبال متقدّم → عرض سيرة → مقصور/قبول/رفض → إشعار للباحث.

### عميل خدمات
[ ] اختيار فئة → طلب (وصف/موقع) → مطابقة/عرض → دردشة → تتبّع حيّ → دفع → تقييم.

### مزوّد خدمة
[ ] ملف احترافي + توثيق → اتصال → طلب وارد (عدّاد) → قبول → ملاحة/دردشة → إنهاء → دفع/تقييم.

### طالب / مدرّب
[ ] تسجيل دورة → تعلّم + اختبار → شهادة → ظهورها في الملف. مدرّب: إنشاء دورة → مراجعة الأدمن → طلاب/إيرادات/Q&A.

### أدمن (ويب)
[ ] تحليلات → توثيق/إيقاف مستخدم → موافقة وظيفة/دورة → حل نزاع → ضبط عمولة/بث.
