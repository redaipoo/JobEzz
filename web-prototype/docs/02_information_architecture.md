# JobEzz — Information Architecture & User Flows (Prompt 2)

## اختيار الدور عند التسجيل
شاشة متعددة الاختيار: باحث عن عمل · صاحب عمل · مزوّد خدمة · عميل · مدرّب/محاضر · طالب.
**حساب واحد يمكنه حمل أدوار متعددة** (مثلاً باحث عمل + عميل خدمات).

## الخريطة (Sitemap) لكل دور

### عميل / مستخدم عام (التنقّل السفلي)
`الرئيسية` → (الركائز الثلاث + أقرب الفنيين + وظائف مقترحة + دورات)
`وظائف` → تصفّح/فلترة → تفاصيل → تقديم
`خدمات` → شبكة الفئات → طلب (وصف/صور/موقع) → مطابقة/عروض → تتبّع → تقييم
`دورات` → كتالوج → تفاصيل → تعلّم/اختبار → شهادة
`حسابي` → الملف/المحفظة/الإعدادات/وضع المزوّد/الأدوات

### مزوّد خدمة (لوحة منفصلة)
تسجيل ملف احترافي (فئة/خبرة/أعمال/هوية/نصف قطر الخدمة) → مفتاح اتصال → طلبات واردة (عدّاد) → مهمة نشطة (ملاحة/دردشة/إنهاء) → لوحة الأرباح/التقييمات/السجل.

### صاحب عمل (لوحة منفصلة)
الملف الشركة (شارة موثّق + الوظائف) → نشر وظيفة → إدارة المتقدّمين (سيرة/مقصور/رسالة/قبول/رفض).

### مدرّب (لوحة منفصلة)
إنشاء/تعديل دورة → رفع محتوى → طلاب مسجّلون وإيرادات → الرد على أسئلة الطلاب (Q&A).

### طالب
كتالوج → تسجيل → تعلّم (فيديو/PDF/اختبار) → شهادة معتمدة تغذّي موثوقيته.

### أدمن (ويب)
نظرة عامة (تحليلات) · المستخدمون (توثيق/إيقاف) · المحتوى (وظائف/فئات/دورات) · النزاعات · الإعدادات (عمولة/مميّز/بث).

## التدفّقات الرئيسية
- **الخدمات (Uber-style):** اختيار فئة → وصف + موقع → (فوري: أقرب موثّق تلقائياً | عروض: عدة مزوّدين) → دردشة → تأكيد وسعر → تتبّع (مقبول→في الطريق→وصل→قيد العمل→مكتمل) → دفع → تقييم + صور.
- **التوظيف:** نشر (صاحب عمل) ↔ تصفّح/تقديم (باحث) ↔ إدارة المتقدّمين ↔ تتبّع الحالة (مقدَّم/قيد المراجعة/مقصور/مرفوض/مقبول).
- **الأكاديمية:** تسجيل → تعلّم ب Bates تقدّم → اختبار → شهادة PDF معتمدة.
