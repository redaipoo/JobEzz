# JobEzz — تطبيق Android (React Native + Expo + TypeScript)

هذا هو **التطبيق الفعلي لأندرويد** لـ JobEzz (تم نقل واجهة النموذج إليه). النموذج السابق `../jobezz/` (HTML/CSS/JS) يبقى كمرجع للتصميم والتفاعل، وهذا المشروع هو ما يُبنى ويُشغَّل على جهاز أندرويد.

## التشغيل
```bash
npm install
npx expo start          # ثم افتح على هاتف عبر Expo Go أو:
npx expo start --android
```

## البنية
```
jobezz-rn/
├─ App.tsx                # NavigationContainer + StackNavigator (كل الشاشات)
├─ app.json / package.json / babel.config.js / tsconfig.json
└─ src/
   ├─ theme.ts           # لوحة الألوان + الحواف (كحلي/أزرق)
   ├─ i18n.ts            # ترجمة ar/en (RTL أولاً)
   ├─ data.ts            # بيانات تجريبية (فئات/مزوّدون/وظائف/دورات/...)
   ├─ store.tsx          # Context (اللغة/الدور/وضع المزوّد/المستخدم)
   ├─ icons.tsx          # أيقونات خفيفة
   ├─ components.tsx      # مكوّنات مشتركة (زر/بطاقة/رأس/نجوم/تبويب سفلي/...)
   └─ screens/
      ├─ Core.tsx         # التعريف، الأدوار، OTP، الرئيسية، الخدمات، الوظائف، الدورات، الحساب، المزوّد، الدردشة
      └─ More.tsx         # صاحب العمل، المدرّب، التطبيقات، الدفع/الفاتورة، التبليغ، النزاعات، الأدمن
```

## الأركان الثلاث
1. **لوحة الوظائف** — تصفّح/فلترة/تفاصيل/تقديم + جانب صاحب العمل + تتبّع الطلبات.
2. **الخدمات عند الطلب (الأهم)** — 29 فئة → طلب (وصف/موقع) → مطابقة فورية أو عروض أسعار → تتبّع حيّ → دفع → تقييم.
3. **الأكاديمية** — كتالوج/تفاصيل/تعلّم/اختبار/شهادة + لوحة المدرّب.

## ملاحظات
- اللغة: **عربية أولاً RTL** مع مبدّل إنجليزي (عبر `useApp().lang`).
- لوحة الأدمن **ويب** كما هو محدّد في المتطلبات: افتح `../jobezz/admin.html` في المتصفح.
- شاشة `Admin` داخل التطبيق توجّه المستخدم إلى لوحة الويب.
- البيانات تجريبية محلية (قابلة للاستبدال بـ Supabase/API لاحقاً).
